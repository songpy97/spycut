# 空格播放与滚轮缩放快捷键修正设计

## 目标

修正设置删除起点后的空格键行为：只要项目已打开，空格始终切换播放或暂停，不得触发当前聚焦按钮的默认点击。时间轴锚点缩放在保留 `Alt/Option + 滚轮` 的同时支持 `Ctrl + 滚轮`，缩放中心、方向、范围和横向平移规则保持不变。

## 方案选择

空格键可以通过设置删除起点后主动移除按钮焦点、给各按钮单独拦截空格，或调整全局快捷键优先级来处理。选择全局优先级方案：在过滤按钮、输入框、滑杆等交互元素之前识别空格，在存在当前项目时阻止默认行为并调用唯一的播放切换入口。主动移除焦点会损害键盘导航，逐按钮处理则容易遗漏新控件；全局处理最符合“空格始终控制播放”的产品语义。

滚轮缩放可以只在 Windows 用户代理下增加 Ctrl 判断，也可以让 `Ctrl + 滚轮` 与现有 Alt 判断走同一条跨平台路径。选择后者，避免平台探测分叉，并确保两种修饰键完全复用既有锚点计算和视口限制。无修饰键、横向滚动及 `Shift + 滚轮` 的平移行为不变。

## 验证

- 应用级测试先聚焦“重设删除起点”按钮，再发送空格，断言默认按钮操作被阻止且播放器收到播放请求。
- 时间轴组件参数化测试分别发送 `Alt + 滚轮` 和 `Ctrl + 滚轮`，断言事件被接管、视口缩小且锚点后的区间位置发生变化。
- 运行前端测试、Svelte/TypeScript 类型检查和 `git diff --check`。Windows 真机鼠标手势仍需在后续原生验收中确认，自动化测试只覆盖 Web 事件逻辑。
