# 音频波形轨道设计

## 目标

在时间刻度与删除区间轨道之间显示源视频第一条音轨的整体波形，让用户通过静音、停顿和句尾的振幅变化快速定位删除边界。波形只用于观察和定位，不改变“项目只保存删除区间”和“源时间轴不可重排”的产品约束。

## 方案

打开或恢复项目后，前端异步请求当前项目的音频波形。Rust 命令先校验 `projectId`，再调用受监督的 FFmpeg：只读取第一条音轨，混合为单声道并降采样为 8 kHz PCM。基础设施层按 20 ms 窗口聚合绝对峰值，返回每秒 50 个 8 位峰值；三小时录屏约 54 万个点，能够分辨讲话停顿，又不会把完整音频加载到前端。命令设置总超时，超时或失败时终止并回收子进程；源文件始终只读。

前端把峰值保存在当前项目的临时内存状态中。`TimelineEditor` 根据共享的 `viewport` 和轨道实际宽度，把当前可见区间聚合为每像素至多一个柱形，并组成单个 SVG path 绘制，因此不会为几十万个峰值创建 DOM 节点，缩放、平移和播放头也天然保持对齐。波形轨道可以像原时间轴一样点击、拖动定位；删除区间仍在独立的下方轨道。生成期间显示“正在分析音频”，无音轨、失败或超时时显示非阻断提示，编辑和导出能力不受影响。切换项目时用请求序号和项目 ID 丢弃迟到结果。

## 验证

- Rust 单元测试覆盖 PCM 分块、峰值聚合、结尾不足窗口和静音输入。
- Svelte 单元测试覆盖加载、就绪、无音轨状态，以及波形轨道参与同一套 scrub。
- App 测试覆盖打开项目后自动请求波形、项目切换时丢弃旧结果。
- 运行 `pnpm check`、`git diff --check`，并在演示界面检查波形、删除区间、播放头和导航条的层级与对齐。
